# Trust Claims Matrix

Last verified: 2026-06-24

This matrix is the control sheet for public trust, privacy, DPA, procurement, pricing, blog, integration, and security copy. It is not legal advice and does not create customer commitments. Binding commitments must be in an executed agreement, order form, DPA, or approved NDA package.

## Global Review Triggers

Do not use these phrases in public or procurement copy without owner approval and evidence attached: `FDA-ready`, `FDA-compliant`, `FDA approved`, `FDA certified`, `exact format`, `ensures`, `guarantee`, `satisfies compliance`, `SOC 2 Type II`, `completed pentest`, `production SLA`, `Native Bidirectional`, `GA`, `session replay`, `Redpanda default`, `WORM`, `Part 11 certified`, `every commit`, `all customer data encrypted with AES-256`, `TLS 1.3 everywhere`.
