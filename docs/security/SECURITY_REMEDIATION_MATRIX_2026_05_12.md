- Agent A: Browser/Auth Surface
- Agent B: Backend/API Security

1. Remove sensitive tokens, emails, callback URLs, and error details from URLs and logs.
2. Stop returning frontend proxy upstream target/error details to clients.
3. Upgrade vulnerable dependency pins and locks.
4. Replace broad credentialed preview-origin CORS matching with explicit allowlists.
5. Harden upload memory limits, content validation, object keys, and serving-origin proof.
6. Expand XSS and CSRF regression coverage for the authenticated app.
