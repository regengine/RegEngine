# Deployment documentation

For the checked-in consolidated backend deployment configuration and release
checks, use [PRODUCTION_DEPLOYMENT.md](PRODUCTION_DEPLOYMENT.md). Confirm the
actual hosting configuration and deployed commit independently; repository
configuration does not prove live status.

The former AWS/ECS instructions at this path described an older multi-service
architecture and referenced files that are no longer present, including the Terraform root configuration, example variables, and
image-push script. They are not a supported deployment procedure.
The previous text remains available in Git history for historical reference.
