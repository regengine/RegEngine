# Design Partner Sales Operating Kit

This folder turns the RegEngine proof plan into a repeatable design-partner motion.

Use it with:

- `docs/product/DESIGN_PARTNER_PROOF_CHECKLIST.md`
- `docs/runbooks/inflow_workbench_design_partner_outreach.md`
- `docs/runbooks/inflow_workbench_design_partner_demo.md`
- `docs/runbooks/first_pilot_session.md`
- `docs/runbooks/design_partner_funnel_operating_rhythm.md`

## Files

| File | Use |
| --- | --- |
| `design_partner_outreach_tracker_template.csv` | Blank prospect and proof-metric tracker |
| `design_partner_feedback_scorecard.md` | Session-level capture immediately after each walkthrough |
| `design_partner_evidence_packet_template.md` | Partner-level evidence rollup for diligence |
| `procurement_trust_packet_template.md` | Buyer/security packet with explicit caveats |

Active prospect trackers and outreach drafts are local-only files because they can contain personal contact data. Keep them out of the public repository.

## Today Sequence

1. Pick one prospect from `docs/research/outreach-top-10-2026-05-14.md` or a warm founder contact.
2. Create or update a local copy of `design_partner_outreach_tracker_template.csv`.
3. Send the relevant email or LinkedIn opener from a local draft or `docs/runbooks/inflow_workbench_design_partner_outreach.md`.
4. If they agree to a session, run `docs/runbooks/inflow_workbench_design_partner_demo.md`.
5. Within 1 hour, complete `design_partner_feedback_scorecard.md`.
6. If they used real or production-like data, start `design_partner_evidence_packet_template.md`.
7. If they ask about security, legal, SOC 2, pentest, or DR, use `procurement_trust_packet_template.md`.

## Weekly Proof Target

The weekly target is not "more demos." It is one stronger proof artifact:

- one real or production-like feed run through Inflow,
- one measured readiness delta,
- one fix queue movement,
- one blocked commit-gate decision,
- one verified export package,
- or one second session scheduled.

## Claim Discipline

Do not turn outreach into marketing claims. A claim becomes usable only after the evidence packet supports it.
